# 六轴机械臂接手调试模板

此副本使用 Craig 改进 DH 和电机集中质量近似，不依赖 URDF。保留控制、回零与保护代码，不包含原机械臂的 DH、映射和质心答案，也不带 Git 历史。

## 参数入口

只需先编辑 `User/gravity/robot_parameters.h`。所有 `FILL_J...` 都必须替换为测量/标定数值，全部核对后将 `ROBOT_PARAMETERS_READY` 改为 1。未填写的模板故意不能生成固件，不要把所有待填参数改成零来绕过检查。

| 字段 | 单位/含义 |
| --- | --- |
| A、ALPHA、D、THETA_OFFSET | m、rad；Craig 改进 DH 的 a、alpha、d、固定角偏置 |
| ENCODER_ZERO | rad；选定参考姿态的真实编码器读数 |
| POSITION_SIGN | +1 或 -1；模型正转与反馈增长的对应关系 |
| TORQUE_SIGN | +1 或 -1；模型补偿力矩与电机力矩方向的关系 |
| MASS | kg；该电机的确认质量，不是原连杆质量 |
| LINK | -1 固定底座；0~5 随 J0~J5 后的连杆运动 |
| COM_X/Y/Z | m；该电机质心在所属连杆 DH 坐标系中的位置 |

仓库没有确认过的电机实测质量，因此 MASS 也保留待填入口。由负责人提供确认质量后填写；旧连杆质量不作为电机质量。

编号：J0 是第一个电机 `motor[0]`；J3 是第四个。底座为坐标系 {0}，`frames[0]` 为经过 J0 后的 {1}，依此类推。LINK=0 表示质量点固定在 {1} 的刚体上。按电机壳体实际随动关系归属，不按电机编号推断。多个电机可以归属同一连杆。

## 计算关系

```text
q = position_sign * (encoder - encoder_zero)
theta = q + theta_offset
A = Rx(alpha) Tx(a) Rz(theta) Tz(d)
模型补偿力矩 = -轴方向 · [(质心位置 - 轴参考点) × 重力]
电机力矩 = 模型补偿力矩 * gain * torque_sign
```

世界/底座 +Z 向上。电机质量点近似忽略轻连杆，不保证全姿态精确悬停；较重支架/夹爪的遗漏会产生误差。模型坐标系变化时，质心与角度映射必须同步核对。

## 先几何，后补偿

1. 定义参考姿态，画轴线与坐标系，测量并填写 DH。
2. 记录参考姿态反馈，逐轴手动转动，核对偏置和位置方向。
3. 用 `GravityComp_EncoderToModelQ()` 得到模型角，调用 `GravityComp_ForwardKinematics()` 查看各级位姿、Z 轴与轴间关系。至少参考姿态、单轴变化、三个组合姿态与实物对照。
4. 确定每个质量点归属、质量和局部质心。用 `GravityComp_ModelTorque()` 看未经增益/电机方向转换的理论力矩；返回 0 表示参数无效，不使用其结果。
5. 支撑机械臂，核对力矩方向，最后逐步提高 `GRAVITY_COMP_GAIN`。默认 0，仅禁止重力前馈，不禁止回零、锁定等主动位置控制。

参考姿态统一定义为 q=0，其 DH 固定角全部填写到 THETA_OFFSET，不再单独设置 MODEL_OFFSET。

回零目标仍是 `motor_function.c` 的编码器零目标，不是 DH 角度。修改映射不会自动改变回零终点。首次烧录前必须确认其是否对应允许的机械姿态；没有确认时不要触发回零。几何观察接口只计算数据，不发送电机命令；普通板端入口仍包含原有按键回零逻辑。

反馈超时、限位和前馈上限保留。纯阻尼故障输出不能保证托住机械臂；协议状态码与时效阈值须实机核对。不得为弥补模型误差直接放宽保护。

## 编译与验证

打开 `MDK-ARM/CtrBoard.uvprojx`，或运行 `tools/build.ps1`。依赖 Keil MDK、Arm Compiler 6.21、STM32F4xx_DFP 3.1.1。

`tools/test_gravity_model.py` 用人工合成机构验证数学，不读取本机械臂答案；`tools/test_motor_control.py` 验证保护、回零及锁定。主机测试需要 MSVC 和 Windows SDK，可通过参数指定路径。

验证记录：数学测试、控制回归和未填参数编译拒绝通过；在临时目录回填虚构参数后 Keil 完整构建为 0 错误、0 警告。临时测试参数及固件已清除，未进行实机烧录。参数文件已加入 Keil 的 gravity 分组。

交付源码故意留空。验证过程中使用过的参数和 HEX 不包含在此目录里。几何验收依据是实物，不以原 URDF 或旧补偿是否好用作为答案。
